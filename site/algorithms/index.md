# Graph Algorithms

The course follows the lectures *MA015 Graph Algorithms* by Jan Obdržálek (Faculty of Informatics, Masaryk University), one lesson per lecture. Every algorithm comes with pseudocode, a step-by-step player, a correctness proof and its running time. It builds on the [Graph Theory](/theory/) course, which it cites for basic notions.
